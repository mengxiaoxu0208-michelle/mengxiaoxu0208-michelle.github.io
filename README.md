# Mengxiao Xu — academic film portfolio

A dependency-free static site for GitHub Pages. The page uses local assets, system fonts and native HTML dialogs.

## Editing

- Edit page copy and dialog content in `index.html`.
- Edit colours, spacing and responsive layouts in `styles.css`.
- `script.js` opens and closes dialogs, stops the film when its dialog closes, and updates the copyright year.
- The contact dialog in `index.html` uses the approved public email `mengxiaoxu0208@gmail.com`.

Keep these public assets in the same directory as `index.html`:

- `portrait.webp`
- `again-poster.webp`
- `guanbu-poster.webp`
- `teaching-directing.webp`
- `mentoring.webp`
- `again-720p.mp4`
- `Mengxiao-Xu-Academic-CV.pdf`

Use the original approved images and public CV. Keep the full Guanbu A Week poster visible. Publication links point to DOI records. The doctorate is described as degree award pending, and creative roles remain distinct from student supervision.

Serve this directory as a static site or publish its contents to the repository’s GitHub Pages source. No build command, package installation, API key or backend is required.
