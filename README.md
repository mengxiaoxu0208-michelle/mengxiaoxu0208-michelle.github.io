A dependency-free static site for GitHub Pages. The page uses local assets, system fonts and native HTML dialogs.

## Editing

- Edit page copy and dialog content in `index.html`.
- Edit colours, spacing and responsive layouts in `styles.css`.
- `script.js` opens and closes dialogs, stops any video when its dialog closes, and updates the copyright year.
- The contact dialog in `index.html` uses the approved public email `mengxiaoxu0208@gmail.com`.
